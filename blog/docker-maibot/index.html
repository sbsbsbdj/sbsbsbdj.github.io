VPS 通过 Docker 部署 maibot

首先部署docker

国内使用阿里云镜像一件脚本

# 1. 下载官方安装脚本并使用阿里云镜像源
curl -fsSL https://get.docker.com | bash -s docker --mirror Aliyun

# 2. 启动 Docker 服务并设置开机自启
sudo systemctl enable --now docker

# 3. 验证安装是否成功
sudo docker run hello-world

配置docker加速

sudo tee /etc/docker/daemon.json <<-'EOF' >/dev/null && sudo systemctl daemon-reload && sudo systemctl restart docker
{
  "registry-mirrors": [
    "https://docker.xuanyuan.me",
    "https://docker.1ms.run",
    "https://docker.m.daocloud.io"
  ]
}
EOF

下载maibot

git clone https://github.com/Mai-with-u/MaiBot.git
cd MaiBot

一键启动

docker compose up -d

webui放行外部ip登录

nano docker-config/mmc/bot_config.toml
//打开配置文件

改为

[webui]

enabled = true

host = ["0.0.0.0"]      # 强制 IPv4

port = 8001            # 保留你设置的值

allowed_ips = ["0.0.0.0"]   # 临时放行所有 IP

最后外部访问port为18001

查找登录token

napcat查看登录token
docker exec napcat cat /app/napcat/config/webui.json

maibot webui登录默认token
docker compose logs core | grep -i "token\|webui.*地址\|访问地址"
